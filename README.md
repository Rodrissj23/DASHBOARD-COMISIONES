# Mi Liquidación — Dashboard de Comisiones

Dashboard personal para controlar ventas, comisión esperada, comisión liquidada y diferencias.

## Estado

Operativo y conectado desde WORK AGENT.

## Objetivo

Tener una vista rápida de la liquidación propia y detectar diferencias sin revisar manualmente todos los registros.

## Integración futura

El siguiente paso es exponer un resumen estructurado para que WORK AGENT pueda responder consultas como:

- cuánto debería cobrar;
- cuánto fue liquidado;
- diferencia total;
- ventas pendientes o con diferencia.

Ver `ROADMAP.md`.
